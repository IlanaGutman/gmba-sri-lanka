02How to add your part

You do not need to know code. Pick the way that suits you.

A

Send text. Open a new issue, pick "Add content", and paste your text. Say which page and which box it belongs to. A teammate or an AI agent puts it on the page.

B

Edit on GitHub. Open the page file, click the pencil, replace the text inside a yellow "To add" box, and choose "Create a new branch and start a pull request".

C

Use your AI agent. Give it the repo link and the brief in the README. It opens a pull request. A teammate reads it before it goes live.

Three rules from the course kit: every claim gets a source with a link. Write tendencies ("meetings often start with tea"), not verdicts about a whole nation. Say where AI was used.
